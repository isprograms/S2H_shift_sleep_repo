# Shift work schedule patterns and sleep outcomes (SHIFT2HEALTH online survey)

Analysis code for: Santonja I, Dros C, Haider S, et al. *Shift work schedule
patterns and sleep outcomes: results from the SHIFT2HEALTH survey across
eight European countries.* Scand J Work Environ Health (online first).

This repository contains the analysis code only. It does **not** include the
survey dataset, fitted model objects, or knitted reports, since these could
allow identification of individual participants.

## Pipeline inputs and intermediate datasets

The pipeline starts from two input files in `raw_data/` (not shared):
`shift_schedules_long.RDS` (one row per reported shift; read by
`01_schedules_cleaning.R`) and `data_edited.RDS` (one row per respondent; read
by `02_initial_data_analysis_and_wrangling.Rmd`). Both are produced outside
this repository, from the survey data export.

From there, each step writes the dataset the next one reads (all in `data/`,
not shared):

| Dataset | Built by | Description |
|---|---|---|
| `shift_schedules_long_edited.rds` | `01_schedules_cleaning.R` | Long-format shifts after manual corrections |
| `data_analysis`, `circular_schedules` | `02_initial_data_analysis_and_wrangling.Rmd` | Analytic sample (one row per participant) and its shifts |
| `schedules_cluster.RDS` | `03_vmf_shift_clusters.Rmd` | Shifts with their VMF cluster assignment |
| `schedules_sleep_long.RDS` | `04_shift_specific_sleep.R` | One row per shift, with cluster, sleep duration and quality |
| `level2_data.RDS` | `05_prepare_model_data.R` | One row per participant, with the relative frequency of each shift cluster |
| `brm_data.RDS` | `05_prepare_model_data.R` | Model dataset: outcomes and scaled/regrouped covariates |



## Notes on `09_classic_metrics_and_sensitivity.R`

This script covers Table 2-3 (Models 1, 2 and the mutually-adjusted Model 4)
and the three sensitivity analyses reported in the supplement: complete-case
analysis (Tables S3-S4), non-informative priors (Tables S5-S6), and
stratification by chronotype (Tables S7-S8). 

## How to reproduce the analysis

1. Clone this repository and place the two input files described above
   (not included) in a `raw_data/` folder.
2. Open R/RStudio with the working directory set to the project root.
3. Run:
   ```r
   source("run_all.R")
   ```
